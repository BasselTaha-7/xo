# XO — Arabic Tic-Tac-Toe

A small, Arabic-language two-player XO game for the browser. Built with plain HTML, CSS, and JavaScript by Bassel Taha.

## Features

- Two players take turns on the same device.
- Detects wins and draws, and prevents moves after the game ends.
- Restart button to begin a new round.
- Keyboard-operable cells, visible focus, and a live status announcement.
- Responsive board that fits smaller screens.

## Run locally

Open `index.html` in a modern browser. No build step or external dependencies are required.

## Tech stack

- HTML5
- CSS3 (Grid, responsive layout)
- Vanilla JavaScript and DOM events
